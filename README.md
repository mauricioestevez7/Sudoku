# Funcion check_sodoku()
---
###### La funcion check_sodoku() se encarga de devolver un booleano si una matriz es sodoku
### Raglas para sodoku:
---
- Tiene que ser una matriz cuadrada
- Tiene que tener todos su valores enteros
- Los numeros se corresponden a la longitud de la fila
- No pueden estar repetido el mismo numero en la fila y columna
